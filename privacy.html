TRANSPARENCIA Y PROTECCIÓN DE DATOS

Política de privacidad

Última actualización: 12 de noviembre de 2026
NEXUS HUB es un espacio personal para organización, estudio y proyectos. Los perfiles de esta versión se crean y funcionan sin conexión a una cuenta online: el contenido personal se guarda cifrado en el dispositivo y no se sincroniza con servidores de NEXUS HUB.

1. Responsable y contacto

Proyecto y aplicación: NEXUS HUB.

Canal de contacto: Soporte y consultas de privacidad en el repositorio oficial. No publiques contraseñas, datos personales ni información privada en incidencias públicas.

2. Perfiles locales y datos que se guardan

Al crear un perfil se guarda en el almacenamiento de este navegador o aplicación un nombre de usuario, parámetros criptográficos y una copia cifrada de los datos de NEXUS HUB. El contenido puede incluir tareas, calendario, horario, notas, proyectos, preferencias y otros datos que decidas introducir.

  • La contraseña no se guarda ni se envía a un servidor. Se utiliza localmente para derivar una clave criptográfica.
  • El contenido del perfil se cifra con AES-GCM de 256 bits; la clave se deriva mediante PBKDF2-SHA-256.
  • La copia de trabajo descifrada se mantiene en el almacenamiento de sesión mientras utilizas la aplicación. La copia persistente del perfil se conserva cifrada.
  • Si activas «Recordar en este dispositivo», se guarda una clave criptográfica local no exportable en IndexedDB para permitir el acceso automático en ese mismo entorno. No se guarda la contraseña.

El perfil local no es una cuenta online, no verifica una identidad y no permite trasladar automáticamente los datos a otro teléfono, navegador o instalación. El almacenamiento de una aplicación Android puede estar separado del almacenamiento de Chrome en el mismo móvil.

3. Servicios externos

NEXUS HUB no incorpora anuncios ni herramientas propias de analítica de uso. Algunas funciones realizan conexiones externas cuando las utilizas:

  • GitHub Pages: aloja y entrega los archivos de la web. El proveedor de alojamiento puede procesar datos técnicos habituales de las solicitudes web.
  • Google Fonts: la interfaz solicita las fuentes Manrope y DM Mono. El navegador contacta con la infraestructura de fuentes de Google para descargarlas. Consulta la política de privacidad de Google.
  • Open-Meteo: si introduces una ciudad para consultar el tiempo, esa ciudad se envía al servicio de geocodificación; después se consultan las coordenadas de esa ciudad para obtener la previsión. NEXUS HUB no solicita la ubicación GPS del dispositivo para esta función. Consulta la información legal de Open-Meteo.
  • Enlaces externos: cuando abres enlaces guardados o enlaces de terceros, se aplican las políticas de los sitios que visitas.

4. Sincronización y versiones anteriores

El acceso actual mediante perfiles locales no utiliza Supabase ni transmite el contenido del perfil para sincronizarlo entre dispositivos. La sincronización experimental de versiones anteriores se ha retirado del cliente actual.

Importante: si utilizaste una versión anterior y llegaste a sincronizar datos en la nube, desactivar esa función en esta versión no elimina automáticamente las copias que ya se hubieran enviado al proyecto de sincronización anterior. Esas copias tendrían que revisarse y eliminarse por separado.

5. Conservación y eliminación

Los datos del perfil permanecen en el almacenamiento local hasta que elimines el perfil, borres los datos del sitio o desinstales/borres los datos de la aplicación. Para eliminar un perfil desde NEXUS HUB, entra en Configuración → Perfil de este dispositivo → Eliminar este perfil y sus datos.

La eliminación del perfil local borra su copia cifrada de ese navegador o aplicación. No elimina archivos JSON que hayas exportado, capturas o copias que hayas guardado fuera de NEXUS HUB. Las copias JSON exportadas desde Configuración no están cifradas; protégelas como cualquier documento que contenga información privada. Si olvidas la contraseña y no tienes activado el acceso recordado ni una copia exportada, el contenido cifrado no se puede recuperar.

6. Seguridad y uso compartido del dispositivo

La contraseña y el cifrado ayudan a proteger el perfil almacenado. Aun así, ningún sistema en un dispositivo compartido puede proteger frente a alguien que controle el dispositivo, el navegador o la sesión ya desbloqueada. No actives «Recordar en este dispositivo» en equipos compartidos y bloquea el dispositivo cuando no lo utilices.

La aplicación Android desactiva la copia automática de datos de la aplicación mediante el atributo de respaldo de Android. El comportamiento de las transferencias entre dispositivos puede variar según la versión de Android y el fabricante.

7. Menores y datos personales

NEXUS HUB puede utilizarse para organizar estudios y actividades personales. Introduce únicamente la información necesaria para esas funciones. No añadas contraseñas de otros servicios, datos bancarios, documentos de identidad ni información especialmente sensible. Los menores deben utilizar el servicio de acuerdo con las indicaciones de sus responsables legales y las normas aplicables.

8. Cambios de esta política

Esta política podrá actualizarse cuando cambien las funciones, los servicios externos o las obligaciones legales. La fecha de la última actualización aparecerá al principio de esta página.
